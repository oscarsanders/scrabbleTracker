# Security policy

## Supported versions

Only the latest release on `main` receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's *Report a vulnerability*
button (Security → Advisories) to send a private report with steps to
reproduce and the affected version. This is a volunteer-maintained project;
expect an acknowledgement within a few days.

The app stores no data and has no accounts. Assumptions and residual risks are
in [`docs/THREAT_MODEL.md`](docs/THREAT_MODEL.md).
